# FileSort (🇺🇸)

A simple Python tool to organize files by type.

## Features

* Detects files in the folder where the script is located
* Organizes files into folders based on their type
* Automatically creates category folders
* Sends unknown file types to the `Others` folder
* Avoids overwriting existing files
* Simple execution through the Python script

# FileSort (🇧🇷)

Uma ferramenta simples em Python para organizar arquivos por tipo.

## Funcionalidades

* Identifica os arquivos na pasta onde o script está localizado
* Organiza os arquivos em pastas de acordo com seu tipo
* Cria automaticamente as pastas das categorias
* Envia tipos de arquivos desconhecidos para a pasta `Outros`
* Evita sobrescrever arquivos existentes
* Execução simples através do script Python
